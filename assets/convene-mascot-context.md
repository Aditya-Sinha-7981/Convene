# Convene Mascot Context

## Overview

The Convene mascot is the visual character of **Convene**, a meeting intelligence and conversation-recording product.

It should feel like a natural extension of the **Convene logo**, not a separate cartoon character.

The mascot takes visual inspiration from the logo's rounded geometric lines and flowing `C` shape. These elements are translated into a simplified character with:

- A rounded, geometric head
- A minimal and expressive face
- A compact body
- Subtle Convene-inspired detailing
- Clean, professional proportions
- Enough simplicity to remain recognizable at very small sizes

The overall personality should be **friendly, professional, modern, and approachable**, without becoming childish or overly cartoonish.

---

## Core Mascot

There is **one core mascot design** for Convene.

The mascot has one dedicated **Convene brand color** that is reserved for the product itself.

The mascot should not be redesigned into multiple different characters. Instead, the same mascot design can be recolored when it is being used as a participant identifier.

The visual system is:

**Convene logo → Core mascot → Participant avatar → Walking animation**

All of these should feel like parts of the same identity.

---

## Participant Avatars

The mascot's **head-only version** is used as the visual identity for participants in the live meeting transcript.

Instead of repeatedly displaying speaker labels such as:

> Tester 1: Hello...

the interface can use:

> `[Mascot Avatar] Hello...`

This works similarly to contact/profile avatars in applications such as WhatsApp.

The avatar does not need to be circular by itself. The UI can place the mascot head inside a circular container.

### Participant Colors

Every participant uses the same mascot design but with a different color.

For example:

- Participant 1 → Purple
- Participant 2 → Blue
- Participant 3 → Orange
- Participant 4 → Green

The color identifies the speaker while the mascot shape establishes the Convene brand.

Participant colors can be dynamically assigned or selected by the participant.

The mascot's reserved Convene brand color should remain distinct from participant colors.

---

## Walking Mascot

The full mascot is also used as a **small walking animation**.

The walking version consists of multiple frames of the same mascot walking, allowing it to be displayed as a sprite animation.

Its purpose is to represent **active processing or waiting states**, rather than being a generic decorative animation.

Possible uses include:

- Processing live audio
- Generating a transcript
- Processing meeting intelligence
- Waiting for AI analysis
- Other intentional loading or processing states

The walking mascot should communicate that **Convene is actively doing something**.

---

## Product Personality

The mascot can also appear in:

- Onboarding
- Empty states
- Processing states
- Product illustrations
- Small product interactions
- Other moments where Convene needs a little personality

It should remain a **supporting visual element**, not the primary focus of the interface.

Convene is a professional meeting/productivity product, so the mascot should add personality without making the product feel like a children's application or a consumer game.

---

## Design Principles

The mascot should be:

- Simple
- Geometric
- Professional
- Friendly
- Recognizable at 20–32px
- Consistent with the Convene logo
- Easy to recolor
- Suitable for both static avatars and animation

It should avoid:

- Excessive detail
- Complex facial expressions
- Overly cartoonish proportions
- A completely different visual language from the Convene logo
- Looking like a generic SaaS mascot

The goal is for a user to see the small mascot beside a transcript message and immediately understand:

**"That is a speaker in this conversation."**

Then, when they see the full mascot walking during processing, they should immediately recognize:

**"That is Convene."**
